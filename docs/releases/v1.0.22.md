# NetSessionTester v1.0.22 build158

## 本次更新

- **Android 底部导航适配（#9）**：API 35 及以上处理系统导航栏 Insets，背景延伸到系统导航区域，按钮内容避开手势条或三键导航区域；API 35 以下保留原布局。
- **iPerf3 TCP 测速修复**：补全独立控制/数据连接、上下行参数与结果交换；停止测试及时关闭连接，失败原因保留显示，无效数据不再保存为成功结果。
- **iPerf3 操作与图表**：端口预设下拉选择并保留手动输入；上下行按钮等宽；10 / 30 / 60 / 120 秒时长，默认 30 秒；实际时间轴、平均线、峰值和点击采样值。
- **版本信息精简**：只展示最近五条正式 Release 信息，移除 Beta 条目与过时说明。

## 下载说明

- Android：`NetSessionTester-v1.0.22-build158-signed.apk`，使用项目发布签名；系统最低要求 Android 8.0。
- 本次仅发布 Android Release 签名 APK；`SHA256SUMS.txt` 提供 APK 校验值。

## 验证范围

- Python 44 项检查、Android iPerf3 8 项协议回归，以及同一源码提交的 Android Release 签名构建。
- 构建通过不等同于真机验收。Android 16 的手势/三键导航、横屏与 Android 14 回归，尤其是 Issue #9 报告的 Galaxy S26 / One UI 8.5，仍需设备反馈。
- iPerf3 当前提供 TCP 上下行测速；目标主机需运行对应端口的 iPerf3 服务，例如 `iperf3 -s -p 5201`。
